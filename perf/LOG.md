- 수치: 5회 중앙값 (최소–최대). 판정 기준은 아래 "판정 규칙".

## 판정 규칙

- 개선/악화: 두 세트의 최소–최대 범위가 겹치지 않을 때만.

- 바이트처럼 회차마다 같은 값은 차이를 그대로 적는다.

## 변경별 기록

### 1. `9a899a5` 첫 페이지 게시글 SSR

- **의도:** HTML → JS → `/api/posts` → 이미지로 이어지던 요청 체인을 끊는다.
- **구현:**
  - 첫 페이지(10개)를 서버에서 조회해 Suspense로 스트리밍한다.
  - 조회 결과를 SWR `fallbackData`로 넘긴다.
- **결과 (직전 대비):**

  | 지표                 | 판정                    | 비고                              |
  | -------------------- | ----------------------- | --------------------------------- |
  | LCP                  | 차이 없음               |                                   |
  | FCP                  | 차이 없음               |                                   |
  | TBT                  | 차이 없음               | 범위가 겹친다. 중앙값은 325 → 458 |
  | JS                   | +6.8 KiB                |                                   |
  | LCP 이미지 요청 시작 | 5,052 → 641 ms (중앙값) | 의도한 효과는 있었다              |

- **LCP가 그대로인 이유:**
  - 게시글 목록이 framer-motion `initial="hidden"`으로 시작해서, 서버 HTML에서도 투명도 0이다.
  - 이미지는 일찍 받지만 하이드레이션과 애니메이션이 끝나야 그려진다.
- **회귀 확인:** 아래 항목을 확인했다.
  - 첫 로드, 날짜 이동(빈 날짜 포함), 무한 스크롤 2페이지
  - 콘솔 에러 없음
  - `/api/*` 요청 구성이 baseline과 같음. 첫 페이지 `/api/posts` 1회는 하이드레이션 후 SWR 재검증 요청이다.

### 2. `adabb4a` SSR 게시글 등장 애니메이션 생략

- **의도:** 서버에서 받은 첫 페이지가 하이드레이션을 기다리지 않고 바로 보이게 한다.
- **구현:**
  - 첫 마운트 때 서버 데이터로 받은 게시글만 `initial={false}`로 바꾼다.
  - 나중에 추가되는 게시글(무한 스크롤 등)은 기존처럼 페이드인한다. 투명도가 0 → 0.71 → 1로 변하는 것을 확인했다.
- **결과 (직전 대비):**

  | 지표        | 판정               |
  | ----------- | ------------------ |
  | LCP         | 5,117 → 2,431 개선 |
  | Speed Index | 5,196 → 3,298 개선 |
  | 점수        | 63 → 84            |
  | CLS         | 0 → 0.078 악화     |

- **CLS 원인:**
  - 날짜 바(react-multi-carousel)는 서버 HTML에서 날짜 항목이 0개라 높이가 0이고, 하이드레이션 후 70px가 된다.
  - 전에는 그 아래 피드가 투명해서 레이아웃 이동으로 집계되지 않았다.
- **회귀 확인:**
  - 1과 같은 항목
  - 서버 HTML의 게시글 `li`가 `opacity:1`인지 확인

### 3. `cff48c8` 날짜 바 높이 고정

- **의도:** 2에서 드러난 레이아웃 이동을 없앤다.
- **구현:** 날짜 바에 `min-h-[70px]`을 지정한다. 하이드레이션 후 높이는 화면 폭 360–1350px에서 모두 70px로 같았다.
- **결과 (직전 대비):**

  | 지표        | 판정                                    |
  | ----------- | --------------------------------------- |
  | CLS         | 0.078 → 0 (5회 모두)                    |
  | LCP         | 차이 없음 (2,431 → 2,434)               |
  | Speed Index | 3,298 → 3,025 개선 (범위가 겹치지 않음) |

- **회귀 확인:**
  - 1과 같은 항목
  - 서버 HTML에 `min-h-[70px]`이 있는지 확인
  - 하이드레이션 후 날짜 바 높이가 70px로 그대로인지 확인
